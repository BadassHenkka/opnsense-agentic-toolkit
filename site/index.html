OPNsense Agentic Toolkit

Let an AI agent work on an OPNsense firewall without giving up review and reproducibility.

  1. 1. Explore (MCP)The agent reads live state: rules, aliases, DNS, routes, WireGuard, backups. Run read-only and nothing can break.
  2. 2. Verify (MCP, optional)A short-lived trial change, staged and applied only on request, then undone.
  3. 3. Implement (Terraform)The end state is Terraform. You review the plan and apply it.

One Go OPNsense API client serves both front ends: mcp-opnsense, a local stdio MCP server, and terraform-provider-opnsense, a Plugin Framework provider. Most resources are generated from OPNsense's own model XML.

Quick start

task build
export OPNSENSE_URL=https://opnsense.lan
export OPNSENSE_API_KEY=...
export OPNSENSE_API_SECRET=...
./bin/mcp-opnsense --check

claude mcp add opnsense --scope user \
  -e OPNSENSE_URL -e OPNSENSE_API_KEY -e OPNSENSE_API_SECRET \
  -- $PWD/bin/mcp-opnsense --read-only

Creating the API user and key is described in the README.
